# Future work

The following questions were deliberately left outside the current preliminary
analysis:

- Define the separate live-damaged plus dead-tree severity metric with Joan and
  Meng before implementing it.
- Compare previous-condition, current-condition, and condition-change-matrix
  approaches if stable numeric CONDID is later relaxed.
- Evaluate alternative mortality annualization or denominator definitions only
  as sensitivity analyses; the current model uses cumulative mortality.
- Investigate why seedling responses differ, including whether disturbance
  evidence represents the microplot areas where seedlings are tallied.
- Add topography, soil, forest type, climate normals, and other controls when the
  final model structure is agreed.
- Decide whether the final analysis should use a causal-inference framework.
- Evaluate nonlinear terms, interactions, spatial structure, and alternative
  uncertainty estimators after the core data definitions are frozen.
