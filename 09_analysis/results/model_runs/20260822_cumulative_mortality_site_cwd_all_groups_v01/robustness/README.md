# Robustness checks

Open `robustness_results.html` for the review-ready summary.

The checks retain the approved cumulative-mortality models and compare them
with identical-history samples, conditions occupying at least 80% of the plot,
state fixed effects, and two CWD-duration formulations. Life-stage interaction
tests use the histories observed for seedlings, saplings, and adults.

The CSV files contain the complete estimates, confidence intervals, sample
sizes, and interaction tests used in the report. These are diagnostics, not a
replacement model run.
